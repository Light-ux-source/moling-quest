## 1. 信息架构

```
首页 S01
  ├─ 章节地图 S02 ── 答题 S03 ── 结算 S04 ── 报告 S05
  ├─ AI 造关 S06 ── 生成中 S07 ── 预览 S08 ── 答题 S03
  ├─ 错题本 S09 ── 重练 S03
  └─ 我的 S11 ── 成就 S10 / 分享 S12 / 排行榜 S13
```

**导航原则**：主流程 5 屏内完成；AI 造关与错题是支线，随时可返回；tabbar 只放 4 项（闯关/探索/错题/我的），结算与报告不占 tab。

## 2. 全局规范

### 2.1 全局状态

| 状态 | 表现 | 出口 |
| --- | --- | --- |
| 加载（页面级） | 纸色骨架块 + 1px 微光，不转圈 | 自动结束 |
| 加载（生成/批改） | 墨团 + 三步进度 + 文案 | 取消/重试（超时后） |
| 空状态 | 墨团 + 一句说明 + 一个 CTA | 去创建/去闯关 |
| 错误 | 原位错误卡 + 原因 + 重试/返回 | 不跳空白页 |
| 离线 | 顶部细条"网络不稳定，正在重试" | 恢复后自动继续 |
| 无权限 | MVP 无此状态；P1 登录后按需 | — |

### 2.2 文案语气

| 场景 | 推荐 | 避免 |
| --- | --- | --- |
| 答错 | "这一处我们再看看" | "你又错了" |
| 未达标 | "再走一遍，这次会不一样" | "挑战失败" |
| 生成失败 | "这次没长出来，再试一次" | "系统错误 500" |
| 等待 | "正在检索资料（1/3）" | "请稍候…" |
| 空错题 | "还没有错题，去走一段新路" | "暂无数据" |
| 额度 | "本月还剩 7 次 AI 造关" | "额度不足，立即充值" |

### 2.3 反馈规则

- 点击 80–150ms 内必须有视觉反馈；提交类按钮进入 loading 并禁用。
- 成功不弹大弹窗，用 toast 或就地状态；失败必须说明"下一步能做什么"。
- 破坏性操作（放弃本关、重新生成）需二次确认。
- 任何长任务都可离开，回来后从服务端状态恢复。

### 2.4 跟踪事件（P1 埋点）

| 事件 | 触发 | 关键参数 |
| --- | --- | --- |
| `page_view` | 进入页面 | page_id, session_id |
| `session_create` | 点击开始/生成 | topic_len, level, count, types |
| `generation_ready` | 轮询到 ready | duration_ms, question_count, sources |
| `generation_fail` | failed | stage, error_code |
| `quiz_answer` | 选择/输入 | qid, type, changed |
| `quiz_submit` | 提交 | answered, total, duration |
| `result_view` | 结算页 | stars, accuracy |
| `report_view` | 报告页 | score, gaps |
| `retry_click` | 重试 | from_stage |
| `share_click` | 分享 | channel |
| `ai_create_start` | 造关 | level, count |

## 3. 核心闭环（5 页）

### S01 首页

| 项 | 说明 |
| --- | --- |
| 目标 | 让用户在 3 秒内决定"今天走哪条路"，并一键继续 |
| 入口/出口 | 启动默认页；→ S02 地图、S06 造关、S03 继续上次 |
| 布局 | 问候区（昵称/连续天数/头像）→ 今日主卡（关卡/题量/时长/最佳星级/CTA）→ 你的章节（2 张进度卡）→ 今日挑战条（可选）→ tabbar |
| 组件 | `HeroCard`、`ChapterMini`、`StreakChip`、`DailyStrip`、`Tabbar` |
| 数据 | 本地最近学习（id/topic/level）；正式版 `GET /api/v1/chapters?limit=2`；当前 MVP 可用 `GET /api/v1/sessions?limit=1` 映射"继续上次" |
| 交互 | 点主卡进地图并定位当前关；点章节卡进对应章节地图；点"全部"进章节列表（P1）；长按章节卡显示"重新开始"（P2） |
| 状态 | 默认；无历史（主卡变为"开始第一关"，隐藏章节）；生成中（主卡显示进度与"查看"）；失败（主卡显示重试） |
| 文案 | 问候"晚上好，旅人"；主卡"第 3 关 · 栈与队列"；副文案不超过 20 字 |
| 验收 | 主卡是唯一 Primary CTA；连续天数与真实数据一致；点击不重复创建会话 |

### S02 章节地图

| 项 | 说明 |
| --- | --- |
| 目标 | 让用户看到"我在哪、下一关是什么、还有多远" |
| 入口/出口 | ← S01；→ S03 答题；→ S05 报告（点已完成节点） |
| 布局 | 顶部返回/章节名/叶币 → 地图画布（路径 + 6 节点 + 当前墨团）→ 底部抽屉（关卡名/题量/最佳星级/CTA） |
| 组件 | `MapCanvas`、`MapNode`、`LevelSheet`、`Mascot` |
| 数据 | `GET /api/v1/chapters/{id}`（P1）；节点状态来自 `progress`；当前 MVP 可由一次会话的 5 道题模拟 5 关，但**不建议长期这样** |
| 交互 | 点节点出抽屉预览；点"开始闯关"进入 S03；未解锁节点点击 toast"完成上一关解锁"；地图可上下轻移（不缩放） |
| 状态 | 默认；全部完成（章末节点变"重走"）；锁定的章末（提示需 3 星）；加载失败（保留上次缓存地图 + 重试） |
| 规则 | 每章 6 关；章末综合关需前 5 关各 ≥3 星；当前关只出现一只墨团 |
| 验收 | 三态区分不只靠颜色；抽屉是唯一 CTA；退出重进定位到当前关；未解锁不可开始 |

### S03 答题

| 项 | 说明 |
| --- | --- |
| 目标 | 让用户专注答完当前题，不迷失、不误触 |
| 入口/出口 | ← S02/S08/S09；→ S04 结算（提交后） |
| 布局 | 顶部章节名 + 题号 + 进度条 → 题型/难度 chip → 题干 → 选项/简答 → 底部上一题/下一题 → 圆点导航 |
| 组件 | `QuizHeader`、`OptionCard`、`ShortAnswerInput`、`QuizFooter`、`DotNav` |
| 数据 | `GET /api/v1/sessions/{id}` 取题（无答案）；`POST /sessions/{id}/answers` 提交 |
| 交互 | 单选/判断点击即选；多选可反选；简答实时计数；上一题保留答案；最后一题变"提交答案"；未答提交二次确认；提交成功跳 S04 |
| 状态 | 正常；已答/未答（圆点）；提交中（按钮 loading）；提交失败（toast + 留在本页）；题目为空（错误卡 + 返回） |
| 文案 | 多选提示"选全才得分"；简答 placeholder"用自己的话写出要点，AI 会按得分点批改" |
| 验收 | 题干区高度固定不抖动；选项文本不截断；提交只触发一次；返回上一题答案不丢；空答按 0 分且有确认 |

### S04 关卡结算

| 项 | 说明 |
| --- | --- |
| 目标 | 先给情绪（星级/印章），再给数据（正确率/用时/经验） |
| 入口/出口 | ← S03 提交后；→ S03 下一关、S05 报告、S09 错题 |
| 布局 | 顶部章节/用时 → 评级卡（三星 + 印章"通关"）→ 三项数据（正确率/用时/连击）→ 经验条 + 解锁提示 → 错题入口 → 底部按钮 |
| 组件 | `StarRating`、`SealStamp`、`StatTile`、`ExpBar`、`WrongEntry` |
| 数据 | 报告接口的 `score/correct/total`；星级与经验由服务端计算（P1），MVP 可前端按 60/80/100 推导但需标注"待服务端" |
| 交互 | 星级逐颗点亮（每颗 120ms，最多 360ms）；印章从上方落下 320ms；点"查看解析"进 S05 并定位错题；点"下一关"进下一关或章末 |
| 状态 | 达标（≥60%）；满星；未达标（主按钮变"重练本关"，不显示"失败"）；无错题（隐藏错题入口） |
| 验收 | 星级阈值正确；未达标无负面词；分享入口不泄题；下一关确实解锁 |

### S05 学习报告

| 项 | 说明 |
| --- | --- |
| 目标 | 回答"我哪里会、哪里不会、下一步做什么" |
| 入口/出口 | ← S04；→ S03 再练、S12 分享、S09 错题 |
| 布局 | 顶部主题/日期/分享 → 分数环 + 等级标签 + 诊断摘要 → 分题型条 → 知识缺口 → 下一步 → 逐题解析（折叠）→ 来源 → 底部按钮 |
| 组件 | `ScoreRing`、`TypeBar`、`GapList`、`NextSteps`、`ReviewAccordion`、`SourceList` |
| 数据 | `GET /api/v1/sessions/{id}/report`；字段见方案设计文档 6.3 |
| 交互 | 逐题默认折叠，点击展开"我的答案/正确答案/反馈/解析/得分要点/来源"；来源点击复制链接；"再练一组"以同主题新建会话；"换个主题"回首页 |
| 状态 | 批改中（墨团 + 文案，轮询完成后再取报告）；报告为空（错误卡 + 重试）；无来源（隐藏来源区）；长文滚动不卡顿 |
| 文案 | 诊断 100–150 字；缺口 2–4 条、每条 ≤30 字；下一步 2–4 条、每条 ≤40 字；禁止"保证提分" |
| 验收 | 缺口来自错题；逐题答案不串位；分享不含题目与答案；报告刷新后仍可看；AI 标识与免责声明可见 |

## 4. AI 造关与错题（4 页）

### S06 AI 造关 · 输入

| 项 | 说明 |
| --- | --- |
| 目标 | 降低"不知道输入什么"的门槛，并建立"会检索、有来源"的信任 |
| 入口/出口 | ← S01 "造一条新路" / 地图"+"；→ S07 生成中 |
| 布局 | 返回 → 标题/说明 → 主题输入（200 字/计数）→ 示例 chips → 难度/题量/题型 → 耗时与来源提示 → 生成按钮 |
| 组件 | `TopicInput`、`ExampleChips`、`OptionChips`、`TrustNote` |
| 数据 | `POST /api/v1/sessions`（P1 增加 `mode=chapter`、`level/count/types`） |
| 交互 | 示例点击填入不生成；至少选一种题型；重复点击只创建一次；生成中禁用并跳 S07 |
| 状态 | 默认；输入非法（内联提示）；额度不足（P1，按钮变"了解额度"）；提交失败（toast + 留在本页） |
| 验收 | 2–200 字校验；题型至少 1 种；创建后 202 立即返回；不重复创建 |

### S07 AI 生成中

| 项 | 说明 |
| --- | --- |
| 目标 | 把 20–40 秒的等待变成可理解、可离开的过程 |
| 入口/出口 | ← S06；→ S08 预览；← 取消回 S06 |
| 布局 | 墨团 orb → 标题（含主题）→ 总进度 → 三步（检索/提炼/出题）→ 小提示 → 取消 |
| 组件 | `GeneratingOrb`、`StepList`、`ProgressBar` |
| 数据 | 轮询 `GET /sessions/{id}`：`status/stage/progress/error` |
| 交互 | 状态真实映射；失败原位显示"重试/换个主题"；>45s 显示"继续等/稍后回来"；取消仅停止轮询，不删除服务端任务（可回来继续） |
| 状态 | queued/searching/digesting/generating/ready/failed；弱网重连；超时 |
| 验收 | 步骤与后端 stage 一致；不出现假进度；失败不白屏；离开再回来能恢复 |

### S08 关卡预览

| 项 | 说明 |
| --- | --- |
| 目标 | 在开始前让用户确认"这组题值不值得做"，并允许重生成 |
| 入口/出口 | ← S07；→ S03；← 重新生成回 S07 |
| 布局 | 返回/“AI 初稿”标签 → 章节卡（主题/关数/题量/来源数）→ 题目列表（题干+题型）→ 来源 → 底部"重新生成/开始闯关" |
| 组件 | `ChapterCard`、`QuestionPreviewList`、`SourcePreview` |
| 数据 | `GET /sessions/{id}`（ready）；来源在 `sources`；不展示答案 |
| 交互 | 点来源复制/预览；重新生成需二次确认，走 `POST /sessions/{id}/regenerate` 复用原会话/章节，**不额外消耗额度**；开始进 S03 |
| 状态 | 正常；来源为空（隐藏区块并说明"本次未联网"）；题目少于预期（提示"生成了 N 题"）；生成失败（错误卡） |
| 验收 | 预览不含答案；来源可回溯；重新生成不重复扣额度（已实现） |

### S09 错题本

| 项 | 说明 |
| --- | --- |
| 目标 | 把"错题"变成可执行的复习清单，而不是羞耻榜 |
| 入口/出口 | ← tabbar/报告；→ S03 重练 |
| 布局 | 标题 + 总数 → 筛选 chips（全部/章节/待复习）→ 优先练卡（3 个高频知识点）→ 错题列表（题型/关卡/错次/我的答案/正确答案/去重练）→ 底部"按知识点组卷" |
| 组件 | `MistakeFilter`、`PriorityCard`、`MistakeItem`、`RetryCTA` |
| 数据 | `GET /api/v1/mistakes`（P1 新增）；字段：question_id/chapter/stem/type/wrong_count/last_answer/correct_answer/knowledge_point |
| 交互 | 筛选即时生效；单题"去重练"进 S03（只练该题）；底部组卷 3–5 题；答对后从列表移除（P1） |
| 状态 | 有错题；空状态（墨团+去闯关）；筛选为空；加载失败 |
| 验收 | 按知识点聚合；同一题只出现一次并显示次数；重练后状态更新；不展示长篇解析 |

### S10 成就与段位

| 项 | 说明 |
| --- | --- |
| 目标 | 记录成长，不制造攀比 |
| 入口/出口 | ← S11；→ 返回 |
| 布局 | 标题 + 当前段位 → 段位卡（徽记/经验/进度/距离下一段）→ 徽章 3×3 → 本周轨迹 → 返回 |
| 组件 | `RankCard`、`BadgeGrid`、`WeeklyChart` |
| 数据 | `GET /api/v1/profile/stats`（P1）：exp/level/badges/weekly |
| 交互 | 点徽章看条件与获得时间；未解锁只显示条件，不显示进度暗示；本周轨迹只读 |
| 状态 | 有数据；新用户（0 经验，显示"第一步"引导）；加载失败 |
| 验收 | 段位阈值一致；徽章不参与排行加成；空数据不显示虚假进度 |

## 5. 成长与社交（4 页）

### S12 分享卡片

| 项 | 说明 |
| --- | --- |
| 目标 | 让用户愿意分享"我走过了这一关"，同时不泄题 |
| 入口/出口 | ← S05/结算；→ 分享好友/朋友圈/保存 |

| 交互 | 预览即最终图；保存到相册需授权；分享落地页未登录可直接答题 |
| 状态 | 生成中；生成失败（重试）；无授权（引导设置） |
| 验收 | 卡片无题目/答案；小程序码可扫；不伪造官方认证；图片 3:4 不变形 |

### S13 排行榜

| 项 | 说明 |

## 6. 页面与接口对照

| 页面 | 现有接口 | 需要新增 |
| --- | --- | --- |
| S01 | `GET /sessions?limit`、本地缓存 | 章节/进度汇总 |
| S02 | — | `GET /chapters/{id}`、`POST /chapters/{id}/progress` |
| S03 | `GET /sessions/{id}`、`POST .../answers` | 题目按关组织 |
| S04 | `GET .../report` | 星级/经验/解锁服务端计算 |
| S05 | `GET .../report` | 分享图 |
| S06 | `POST /sessions` | 章节模式、额度 |

1. **“探索”tab → S06 造关页**：原型没有独立“探索”页（用户已确认按此映射）。
2. **“错题/我的”tab 置灰**：本次范围 S01–S08；点击提示“下一版开放”，不伪造页面。
3. **S02 去掉“本章进度”卡**：原型只有地图 + 底部抽屉；实现严格按原型，进度通过节点与抽屉表达。
4. **S05 逐题解析内联折叠**：按 docs/03 “逐题默认折叠”实现；底部保留“换个主题/再练一组”。
5. **S08 列表展示“标题 + 题干前两行”**：docs/03 要求“题干+题型”；比线框多一行题干，便于确认真题。
6. **H5 使用 hash 路由**：直接访问页面需 `/#/pages/...`；小程序端不受影响。
7. **首页 Mock 标识**：Mock 模式显示“Mock 演示模式”，避免误判生成质量；真实模式自动隐藏。
8. **字体**：H5 尝试 Google Fonts，失败回退系统宋体/楷体；小程序用系统字体（ADR-014）。

**章节映射（ADR-017）**：一次生成 = 一章；5 题 = 5 个地图节点；第 6 节点“章末 · 综合”需前 5 关均 3 星后按需再生成 3 题；节点星级=答对 3/部分分 1/答错 0，章节星级=60/80/100 阈值。
