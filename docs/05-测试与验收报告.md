## 5. 复现步骤

```bash
# 0) 后端（先启动独立 MySQL 3307）
cd backend
./scripts/start_mysql_dev.sh
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
cp .env.example .env          # MYSQL_PORT=3307；可留空 DEEPSEEK key
.venv/bin/uvicorn app.main:app --port 8000

# 1) 测试
.venv/bin/python -m pytest -q

# 2) 前端构建
cd ../miniapp
npm install
npx tsc --noEmit
npm run build:weapp
npm run build:h5

# 3) H5 预览 + 演示数据
python3 scripts/serve_h5.py dist-h5 10087 &
../backend/.venv/bin/python scripts/seed_demo.py --reset

# 4) E2E / 截图
node scripts/e2e.js
node scripts/screenshot.js
```

> H5 默认 hash 路由：直接访问页面用 `http://127.0.0.1:10087/#/pages/...`。
