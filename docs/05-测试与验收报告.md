## 4. 已知限制

| ID | 问题 | 影响 | 临时方案 |
| --- | --- | --- | --- |
| K-01 | 无登录，`client_id` 设备级 | 换设备不同步 | 本地缓存 + 明确提示 |
| K-02 | 限流在进程内存 | 多实例失效 | 单实例；P1 Redis |
| K-03 | SQLite 单写 | 高并发可能锁 | WAL + 短事务 |
| K-04 | Mock 数据固定 | 不代表真实质量 | 真实联调已完成 1 组；评测集待做 |
| K-05 | H5 Google Fonts 不可达时回退系统宋体 | 字形/换行略有差异 | ADR-014 系统回退 |
| K-06 | 微信端 SVG 由 `<image>` 渲染 | 不支持 `<style>`/百分比 | 生成脚本已规避 |
| K-07 | 章末综合需前 5 关满星 | 门槛较高 | P1 可调整 |
| K-08 | 日挑战仅 3 题 + 30 经验 | 内容有限 | 后续按薄弱点生成 |

## 5. 复现步骤

```bash
# 0) 后端（Mock；填 Key 后自动真实）
cd backend
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
cp .env.example .env          # 可留空
.venv/bin/uvicorn app.main:app --port 8000

# 1) 测试
.venv/bin/python -m pytest -q

# 2) 前端构建
cd ../miniapp
npm install
npx tsc --noEmit
npm run build:weapp
npm run build:h5

# 3) H5 预览 + 演示数据
python3 scripts/serve_h5.py dist-h5 10087 &
SQLITE_PATH=../backend/data/app.db ../backend/.venv/bin/python scripts/seed_demo.py --reset

# 4) E2E / 截图
node scripts/e2e.js
node scripts/screenshot.js
```

> H5 默认 hash 路由：直接访问页面用 `http://127.0.0.1:10087/#/pages/...`。
