## 1. 背景与问题

原始需求只有四句话：用户输入想学的知识 → AI 全网检索 → 生成题目 → 回答后给答案解析，并希望是"对话式学习"。

真正要解决的问题有三个：

| 问题 | 表现 | 本产品的回答 |
| --- | --- | --- |
| 学习枯燥、留存低 | 读完记不住，缺少主动回忆与即时反馈 | 把学习拆成 3～5 分钟一关，答题即反馈 |
| 不知道该学什么、学到哪 | 没有路径，知识是散的 | 章节地图 + 逐关解锁 + 学习报告 |
| 不信任 AI 内容 | 怕幻觉、怕答案错 | 联网检索 + 来源引用 + 结构化校验 + 明确 AI 标识 |

**产品定位一句话**：把任何一个知识点，变成一条可以"走"的闯关路径，并在每一关之后告诉你下一步。

## 2. 目标与非目标

### 2.1 目标（按优先级）

| 优先级 | 目标 | 衡量方式 |
| --- | --- | --- |
| P0 | 核心闭环可完赛 | 创建 → 出题 → 答题 → 结算 → 报告，Mock 与真实模型均可跑通 |
| P0 | 生成质量可用 | 结构合法率 ≥95%，人工抽检可用率 ≥90% |
| P0 | 等待可解释、失败可恢复 | 生成 P90 ≤45s；失败有重试，不白屏 |
| P1 | 形成回访理由 | 错题本、成就、连续学习、AI 造新关 |
| P1 | 可传播 | 分享卡片不含题目与答案 |
| P2 | 轻社交 | 排行榜（默认关闭，未成年人保护） |

### 2.2 非目标（明确不做）

| 不做 | 原因 | 重新评估条件 |
| --- | --- | --- |
| K12 学科培训 | 资质与政策风险高 | 不做 |
| 支付与会员（MVP） | 先验证完赛与留存 | 留存达标后 |
| 多轮自由对话 | 成本与交互复杂度高；先做结构化闯关 | P1 后期，基于错题追问 |
| 用户自建题库/上传 PDF | 解析与版权成本高 | P1 后期 |
| 多语言 | 目标用户为中文 | 视增长 |
| 深色模式 | IP 的治愈感依赖纸白；两套主题维护成本高 | 有明确夜间使用数据后 |

## 4. 用户与场景

| 画像 | 场景 | 关键诉求 | 设计含义 |
| --- | --- | --- | --- |
| 备考型 | 通勤、睡前刷 5 题 | 覆盖考点、知道哪里不会 | 章节地图、错题本、知识缺口 |
| 转岗/充电型 | 学新框架/新领域，看完就忘 | 快速自测、补漏 | AI 造关、来源可信、难度分层 |
| 兴趣型 | 好奇某个概念 | 低门槛、不打击信心 | 三星阈值友好、失败文案不指责 |

**核心旅程**：打开 → 看到"今天走哪条路" → 进入地图 → 闯一关 → 看结算 → 看报告 → 再练/换主题。

**情绪曲线**：好奇（首页）→ 专注（答题）→ 紧张（提交）→ 释放（结算）→ 认知（报告）。UI 的吉祥物只在"好奇/紧张/释放"出现。

## 5. 功能需求

> 编号规则：`FR-xx`。状态：✅ 已实现（功能）/ 🎨 设计已确认待实现 / ⏳ 未开始 / 🅿️ P2。

### FR-01 主题输入

| 项 | 内容 |
| --- | --- |
| 描述 | 用户输入 2～200 字的学习主题，可点示例快速填入；支持难度、题量、题型选择 |
| 优先级 | P0 |
| 状态 | ✅ 功能 + 新 UI（v0.2.0） |
| 页面 | S01 首页（入口）、S06 AI 造关输入 |
| 验收 | 输入 <2 字提示"先输入想学习的知识点"；>200 字截断并计数；示例点击只填入不直接生成；重复点击提交只创建一次会话 |

### FR-02 章节地图

| 项 | 内容 |
| --- | --- |
| 描述 | 以路径节点展示章节内关卡；已完成、当前、未解锁三态；章末综合关需 3 星解锁 |
| 优先级 | P0 |
| 状态 | ✅ 已实现（v0.2.0，章节模型 + S02） |
| 页面 | S02 |
| 验收 | 未解锁节点不可开始；当前节点高亮且只出现一只墨团；点击节点先出底部抽屉预览，再开始；退出重进进度保持 |

### FR-03 AI 出题

| 项 | 内容 |
| --- | --- |
| 描述 | 服务端异步执行：检索 → 知识提纲 → 生成 3～10 道题 → 校验入库；支持单选/多选/判断/简答 |
| 优先级 | P0 |
| 状态 | ✅ 后端 + S07 生成中页面 |
| 页面 | S07 生成中、S08 预览 |
| 验收 | 创建接口 202 立即返回；轮询可见 searching/digesting/generating；ready 后返回题目且**不含答案与解析**；检索失败自动降级纯模型；题目少于请求数时允许但至少 1 题；单题非法即丢弃 |

### FR-04 答题

| 项 | 内容 |
| --- | --- |
| 描述 | 一题一屏；单选/判断点击即选，多选可反选，简答输入 ≤600 字；可上一题、跳题、圆点导航 |
| 优先级 | P0 |
| 状态 | ✅ 功能 + 新 UI（v0.2.0） |
| 页面 | S03 |
| 验收 | 题干区高度固定，选项数量变化不推动底部按钮；未答提交二次确认并按 0 分计；已答状态在圆点可见；返回上一题保留答案 |

### FR-05 判分

| 项 | 内容 |
| --- | --- |
| 描述 | 客观题规则判分；多选漏选给部分分；简答按 rubric 由 LLM 判分，失败降级为要点覆盖率 |
| 优先级 | P0 |
| 状态 | ✅ 已实现 |
| 页面 | S04 结算、S05 报告 |
| 验收 | 单选/判断 0/1；多选漏选 `0.5×选对/正确数`，错选 0；简答 ≥0.6 通过；空答统一 0 分并给"未作答"反馈；LLM 失败仍能出报告 |

### FR-06 关卡结算

## 7. 数据与隐私

| 数据 | 是否收集 | 用途 | 保留 |
| --- | --- | --- | --- |
| 学习主题 | 是 | 生成题目 | 7 天（匿名） |
| 题目与答案 | 是 | 判分、报告、错题本（P1） | 30 天 |
| 昵称/头像 | P1 登录后 | 展示与分享 | 账号存续期 |
| 手机号 | 否 | — | — |
| 设备/IP | 仅日志 | 限流与安全 | 7 天 |

**原则**：不收集与学习无关的信息；不用于模型训练；用户可请求删除；分享前默认脱敏。

## 10. 端到端验收场景

| ID | 场景 | Given / When / Then |
| --- | --- | --- |
| E2E-01 | 首次学习 | 给定无 Key 的 Mock 环境，输入主题并开始，则 45s 内看到题目，答完能看到报告 |
| E2E-02 | 生成失败 | 给定检索与模型均失败，则状态变为 failed 且给出"重试/返回"，不白屏 |
| E2E-03 | 未答提交 | 给定 2 题未答，提交时二次确认，确认后按 0 分计入报告 |

| E2E-07 | 弱网 | 轮询中随机断网 3 次，恢复后能继续，不重复创建会话 |
