| # | 任务 | 价值 | 依赖 | 验收 |

## 4. 技术债

| ID | 债 | 影响 | 建议 |
| --- | --- | --- | --- |
| T-01 | 无登录，`client_id` 设备级 | 跨端不同步/可清 | M4 openid |
| T-02 | 限流进程内 | 多实例失效 | Redis |
| T-03 | SQLite 单写 | 并发锁 | PG + 连接池 |
| T-04 | 无定时清理 | 数据增长 | 清理任务（7/30 天） |
| T-05 | 无结构化日志/监控 | 排障慢 | JSON 日志 + Sentry/Prometheus |
| T-06 | 无 CI | 回归靠手工 | GitHub Actions |
| T-07 | 无前端单测/视觉回归 | UI 漂移 | Vitest + 截图 diff |
| T-08 | 无黄金评测集 | Prompt 改动无回归 | 30 条黄金集 |
| T-09 | 报告 JSON 快照不可查询 | 统计受限 | 需要时拆 report_items |
| T-10 | H5 字体依赖 Google Fonts | 字形差异 | 子集字体托管 |
| T-11 | 无 `hover-class` 全量 | 部分机型按下无反馈 | 组件层补 |
| T-12 | `max_session_age_days` 未使用 | 配置误导 | 清理任务启用 |

## 6. Definition of Done

**功能**
- [ ] 主流程可完赛；失败有重试；空/错状态不白屏。
- [ ] 接口契约与 `docs/09` 一致；客户端隔离正确。
- [ ] 答案不下发；报告快照稳定。

**质量**
- [ ] pytest 全绿；新增逻辑有单测/接口测试。
- [ ] `tsc --noEmit`、weapp/h5 构建通过。
- [ ] E2E 主流程 + 三档响应式通过。
- [ ] 视觉截图与原型一致；差异记录在 docs/03。

**上线**
- [ ] 真实 Key 校准；P90/成本达标。
- [ ] 微信真机；内容审核；隐私政策；备案/类目。
- [ ] 监控/备份/回滚演练。
