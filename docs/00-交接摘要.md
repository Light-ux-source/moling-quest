## 3. 真实模型配置（重要）

`backend/.env` 已配置（Key 在本地，已 gitignore；**不要提交/打印**）：

```bash
LLM_PROVIDER=deepseek
DEEPSEEK_BASE_URL=https://ws-<workspace>.maas.aliyuncs.com/compatible-mode/v1
DEEPSEEK_MODEL=deepseek-v4.1-flash-1017
ENABLE_WEB_SEARCH=false
DEEPSEEK_SEARCH_BASE_URL=https://api.deepseek.com
```

- 这是**阿里云 MaaS OpenAI 兼容网关**，不是 DeepSeek 官方：
  - 必须 `/compatible-mode/v1`；`deepseek-flash` / `/api/v1` 会 404；
  - 网关**没有** DeepSeek 官方 Search API，所以关闭联网检索；真实模式用 `NoopSearchClient`，不伪造来源。
- 切回官方：`DEEPSEEK_BASE_URL=https://api.deepseek.com`、`DEEPSEEK_MODEL=deepseek-flash`、`ENABLE_WEB_SEARCH=true`、`DEEPSEEK_SEARCH_BASE_URL=https://api.deepseek.com`。
- 真实单组实测：tokens 约 2.9k/2.1k，¥0.022–0.023，创建→完成 15–20s（含作答）。

## 5. 架构 10 行

```
Taro H5/weapp (S01–S08)
  → FastAPI /api/v1（X-Client-Id）
    → routes → services（question_gen/grading/reporting/chapters/settlement）
      → chains（LangChain LCEL：digest/generate/grade/report）
        → ChatDeepSeek | MockChatModel
        → Search API（httpx；当前网关关闭）
      → db.py（SQLite WAL：sessions/chapters/questions/answers/reports）
```

- 一次生成 = 一章；5 题 = 5 个地图节点；第 6 节点章末综合需前 5 关满星。
- 答案不下发；报告 JSON 快照；`session_id` 是凭证，`client_id` 隔离章节/统计。
- Prompt 模板在 `app/prompts.py`；LCEL 在 `app/chains/pipeline.py`；Mock 数据在 `app/chains/mock_data.py`。

## 7. 当前坑/注意

1. H5 是 hash 路由：直接打开页面用 `/#/pages/...`。
2. Taro 页面切换时旧页仍在 DOM；E2E 等 800ms 再测布局，截图用 `.page-shell:visible`。
3. 微信端 SVG 用 `<image>`，不支持 `<style>`/百分比；资源必须由 `gen_assets.py` 生成。
4. 字体 Google Fonts 不可达时回退系统宋体/楷体，换行会有差异。
5. SQLite 单写；多 worker 可能锁，MVP 用 1 worker。
6. 无登录；换设备/清 localStorage 会丢章节/统计（报告仍可按 sessionId 打开）。
7. 真实模式若 404：先检查 Base URL 是否 `/compatible-mode/v1`、模型 ID 是否网关返回的 ID、Search 是否关闭。
8. `.env` 已 gitignore；不要把 Key 写进代码/文档/日志。
