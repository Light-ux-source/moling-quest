## 1. DeepSeek API

| 项 | 结论 | 来源 |
| --- | --- | --- |
| 模型名 | `deepseek-flash`（已升级为 DeepSeek-V4.1-Flash-1017，调用方式不变）；另有 `deepseek-v4-pro` | [首次调用 API](https://api-docs.deepseek.com/zh-cn/) |
| Base URL | `https://api.deepseek.com`（OpenAI 兼容） | 同上 |
| JSON Output | 必须传 `response_format={"type":"json_object"}`；system/user prompt 必须含 `json` 字样并给出 JSON 示例；空 `content` 需兜底重试 | [JSON Output](https://api-docs.deepseek.com/zh-cn/guides/json_mode) |
| 思考模式 | **默认开启**；必须显式 `{"thinking":{"type":"disabled"}}` 才关闭；开启时 `temperature` 不生效；思考强度 `reasoning_effort=low/high/max` | [思考模式](https://api-docs.deepseek.com/zh-cn/guides/thinking_mode) |
| Search API | `POST /v1/tools/search`；字段 `query/count/need_content`；返回 `rerank_score` 0～3，**≥1.5 为优质结果**；QPS 100；按成功请求计费 5 元/1000 次 | [网页搜索与抓取](https://api-docs.deepseek.com/zh-cn/guides/search) |
| Fetch API | `POST /v1/tools/fetch`，返回 Markdown；QPS 25 | 同上 |

**落到代码的修正**：
1. `app/search.py` 的 `MIN_RERANK_SCORE` 从旧值 `0.6` 改为 **1.5**（旧阈值会把低质来源收进 Prompt）。
2. `ChatDeepSeek` 初始化时 `extra_body={"thinking":{"type":"disabled"}}`；开启时加 `reasoning_effort=high`。
3. `model_kwargs={"response_format":{"type":"json_object"}}`；Prompt 均含 `JSON` 字样。
4. `app/chains/pipeline.py` 对空 `content` 自动重试一次。

## 2. LangChain

| 包 | 版本 | 说明 |
| --- | --- | --- |
| `langchain-core` | **0.3.86** | Python 3.9 可安装的最新 0.3.x |
| `langchain-deepseek` | **0.1.4** | 官方 DeepSeek 集成，提供 `ChatDeepSeek` |
| `langchain-openai` | **0.3.35** | `langchain-deepseek` 的依赖 |
| `openai` | **2.48.0** | 透传客户端 |

**版本约束（实测）**：
- `langchain 1.4.9` / `langchain-core 1.7.6` 要求 **Python ≥3.10**，当前项目 Python 3.9 无法安装。
- `langchain-deepseek 0.1.4` 与 LangChain 1.x 的 `langchain-core` **依赖冲突**（`pip` 报 `ResolutionImpossible`）。
- 因此本项目锁定 **0.3.x 稳定线**；升级 Python 3.12 后可重审是否切 1.x。若切 1.x，`ChatDeepSeek` 暂无兼容版本，需改用 `ChatOpenAI(base_url="https://api.deepseek.com")` 走 OpenAI 兼容协议。

**用法（本地实测通过）**：
```python
from langchain_deepseek import ChatDeepSeek

model = ChatDeepSeek(
    model="deepseek-flash",
    api_key=...,
    api_base="https://api.deepseek.com",
    temperature=0.3,
    max_tokens=4000,
    timeout=120,
    max_retries=2,
    model_kwargs={"response_format": {"type": "json_object"}},
    extra_body={"thinking": {"type": "disabled"}},
)
```
- `BaseChatOpenAI._default_params` 会透传 `model_kwargs` / `extra_body`；
- `model.bind(temperature=..., max_tokens=...)` 可按任务覆盖采样参数；
- token 统计从 `AIMessage.usage_metadata` 读取（`input_tokens` / `output_tokens`）；
- 官方参考：[ChatDeepSeek integration](https://docs.langchain.com/oss/python/integrations/chat/deepseek)。

**代码落点**：
- `backend/app/chains/prompts.py`：`ChatPromptTemplate`（mustache，JSON 示例无需转义）
- `backend/app/chains/pipeline.py`：LCEL `prompt | model | parser`
- `backend/app/chains/models.py`：`ChatDeepSeek` 工厂 + `MockChatModel`
- `backend/app/llm.py`：对外统一 `run(task, variables, context)`

## 3. Taro / 微信小程序

| 项 | 结论 | 来源 |
| --- | --- | --- |
| 版本 | 本机已安装 `@tarojs/cli 4.3.2`；工程为官方脚手架结构 | 本地 `npm ls` |
| 初始化 | `taro init myApp`；本项目已有官方脚手架，不重复生成 | [安装及使用](https://docs.taro.zone/docs/GETTING-STARTED)（镜像：[taro-docs](https://github.com/NervJS/taro-docs/blob/master/docs/GETTING-STARTED.md)） |
| 设计稿 | 750 设计稿；CSS 中 `px` 由 Taro 转 `rpx`（小程序）/`rem`（H5）；原型 1px = 代码 2px | 本地构建产物实测 |
| H5 路由 | 默认 **hash** 路由；直接访问页面需 `/#/pages/...`，静态服务需 SPA 回退 | 本地实测 |
| 资源复制 | `copy.patterns[].to` 相对项目根目录解析（不是 outputRoot），需写成 `${outputRoot}/assets` | Taro `WebpackPlugin.getCopyWebpackPlugin` 源码 |
| 微信 `<image>` | 官方支持 JPG/PNG/**SVG**/WEBP/GIF；SVG 不支持 `<style>`、百分比单位；`scaleToFill` 在 WebView 下居中，需 `preserveAspectRatio="none"` | [image 组件](https://developers.weixin.qq.com/miniprogram/dev/component/image.html) |
| 自定义导航 | `navigationStyle: "custom"`；用 `getWindowInfo().statusBarHeight` + `getMenuButtonBoundingClientRect()` 计算头部高度并避让胶囊 | 本地实现 |
| 字体 | H5 尝试 Google Fonts（`display=swap`），失败则回退 STKaiti/Songti；小程序不加载外部字体，避免阻塞首屏 | ADR-014 |

**资源方案**：Taro 小程序端不支持 JSX 内联 `<svg>`，因此用 `scripts/gen_assets.py` 从原型 SVG 生成 `src/assets/{icons,mascot,map}`，通过 `<Image src="/assets/...">` 使用；构建时复制到 `dist/assets` 与 `dist-h5/assets`（ADR-019）。

## 4. 本次核实发现的既有问题

| 问题 | 影响 | 处理 |
| --- | --- | --- |
| `rerank_score` 阈值 0.6 | 低质来源进入 Prompt，影响出题可信度 | 改为 1.5，并加单测 |
| JSON mode 空 content | 偶发解析失败 | 链执行器重试一次，仍失败转 `LLMError` |
| H5 直接访问 `/pages/xxx` 落到首页 | 截图/E2E 链接错误 | 统一使用 `/#/pages/...` |
| `copy.to: 'assets'` 复制到项目根目录 | 小程序 404 | 改为 `${outputRoot}/assets` |
| 缺失 `arrow-right-ink3.svg` | 答题页上一题图标 404 | 改用已有 `arrow-right-ink`，加资源扫描 |
