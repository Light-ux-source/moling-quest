## 5. 版本与维护

| 规则 | 说明 |
| --- | --- |
| 版本号 | `v主.次`；主版本=范围/结构变化，次版本=补充与修正 |
| 更新触发 | 需求变更、UI 评审、接口变化、发布、重大缺陷复盘 |
| 评审 | 需求与 UI 需产品/设计确认；接口与数据需后端确认；发布需至少一人按检查清单过一遍 |
| 归档 | 过期内容不删除，移到“历史决策”并注明失效日期与替代文档 |
| 同步 | 代码 PR 涉及行为变化时，必须同时更新 `03`/`05`/`09`/`10` 中至少一个，否则不合入 |
| 链接 | 新增/移动文档后跑 `scripts/check_docs_links.py`（见 §7） |
