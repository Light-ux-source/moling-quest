## 1. 设计理念

### 1.1 一句话

> 把学习进度做成一条雾林小路，AI 是一只陪你走的黑猫灵。

### 1.2 四个视觉基因

| 基因 | 来源 | 在 UI 中的表现 |
| --- | --- | --- |
| 雾林 | 清晨森林的漫射光 | 低饱和绿、灰蓝、大面积留白、柔和径向渐变 |
| 宣纸 | 纸张纤维与毛边 | 米白底、细颗粒、微旋转卡片、纸胶带 |
| 墨迹 | 毛笔的浓淡与飞白 | 手绘下划线、墨线分隔、朱砂印章 |
| 琥珀光 | 猫瞳与暖光 | 当前关卡、经验、猫眼、关键强调 |

### 1.3 五条原则

1. **内容优先**：装饰不得遮挡题干、选项与按钮；任何纹理的对比度都要低于文字。
2. **一屏一事**：每屏只有一个主行动（首页"继续闯关"、地图"开始闯关"、结算"下一关"）。
3. **克制的游戏化**：星级、经验、连击是反馈，不是压力；不出现倒计时闪烁、红黑警报式设计。
4. **可解释的等待**：长耗时拆成三步，状态真实映射后端，不做假动画。
5. **手作但不脏**：微旋转、错位、飞白都是受控的（±0.5°、≤2px），不是随机混乱。

### 3.3 使用规则

- **琥珀不做正文**：只用于大面积色块、图标、星级、当前节点；若必须写字，用 `--amber-deep` 或松烟。
- **朱砂不做长文**：只用于印章、错误提示、删除；正文错误文案用松烟 + 朱砂图标。
- **不用纯黑纯白**：最大对比用松烟/素笺，避免屏幕上的"硬边"。
- **深色模式不做**：治愈感依赖纸白；如未来要做，需重新测对比度并新增一套令牌，不能直接反色。

## 4. 字体系统

### 4.1 字体家族

| 角色 | 字体 | 回退 | 说明 |
| --- | --- | --- | --- |
| 展示/标题 | Ma Shan Zheng | STKaiti → KaiTi → Songti SC | 毛笔手写，仅用于短标题；不用于正文 |
| 正文/标题 | Noto Serif SC | Songti SC → STSong → serif | 宋体保证长文阅读与纸感 |
| UI/数字 | 系统无衬线 | PingFang SC / system-ui | 按钮、标签、数字、表单 |

**加载策略**：Web/H5 用 Google Fonts（`display=swap`）；小程序端 `wx.loadFontFace` 需 HTTPS + CORS，MVP 建议直接用系统楷体/宋体回退，不阻塞首屏。字体只加载 400/700 两个字重。

### 4.2 字号与行高

| 层级 | 原型 px | Taro rpx（750 设计稿） | 行高 | 用途 |
| --- | --- | --- | --- | --- |
| Display | 44–76 | 88–152 | 1.2 | 封面/章节名 |
| H1 | 40 | 80 | 1.25 | 页面大标题 |
| H2 | 28 | 56 | 1.3 | 区块标题 |
| H3 | 20 | 40 | 1.4 | 卡片标题 |
| 题干 | 19 | 38 | 1.65 | 答题题干 |
| 正文 | 15–16 | 30–32 | 1.75 | 段落、解析 |
| 辅助 | 12–13 | 24–26 | 1.6 | 元数据、说明 |
| 最小 | 10（仅英文标签） | 20 | 1.4 | 状态栏等非关键信息 |

**规则**：正文不小于 12px（≈24rpx）；中文不使用全大写；数字用 `font-variant-numeric: tabular-nums` 保证对齐。

### 4.3 排版细节

- 标题字距 `0.01em`，毛笔标题可 `0.04em`；正文不加字距。
- 段间距 12–16px；长文最大宽度 680px（H5），小程序全宽但左右留 20px。
- 强调用颜色/字重，不用斜体（中文斜体可读性差）。

## 5. 空间与形状

### 5.1 间距（4/8 节奏）

`4 · 8 · 12 · 16 · 20 · 24 · 32 · 40 · 48 · 64 · 80`

| 场景 | 值 |
| --- | --- |
| 图标与文字 | 8 |
| 卡片内边距 | 20–28 |
| 卡片间距 | 16–24 |
| 区块间距 | 32–48 |
| 页面左右留白 | 20（小程序）/ 28（H5 桌面） |
| 底部固定栏上方留白 | 84–96 |

### 5.2 圆角

| Token | 值 | 用途 |
| --- | --- | --- |
| `--radius-s` | 12px | 标签、输入框、小按钮 |
| `--radius-m` | 20px | 选项卡、普通卡片 |
| `--radius-l` | 28px | 主卡片、弹层 |
| `--radius-xl` | 40px | Hero、底部抽屉 |
| `--radius-pill` | 999px | 主按钮、chip、进度条 |

### 5.3 描边与阴影

```css
--border-width: 1.5px;
--shadow-s: 0 2px 0 rgba(35,40,31,.08);
--shadow-m: 0 14px 30px -20px rgba(35,40,31,.5);
--shadow-l: 0 32px 60px -36px rgba(35,40,31,.55);
--btn-depth: 4px;                 /* 主按钮底部实色厚度 */
```

- 卡片用 1.5px 半透明墨线 + 柔和投影，不用纯灰边框。
- 主按钮用"实色厚度"而非模糊阴影：`box-shadow: 0 4px 0 var(--moss-deep)`。
- 禁止在正文区域使用毛玻璃/强模糊。

### 5.4 纸张肌理

- 实现：一层 SVG `feTurbulence` 噪点（opacity 0.05–0.09，`mix-blend-mode: multiply`）+ 两三个径向渐变光斑。
- 小程序注意：部分基础库对 `data:image/svg+xml` 背景支持不一致，落地时优先预生成 256×256 PNG base64，或只用 CSS 渐变。
- 颗粒永远在内容之下（`z-index: 0`，`pointer-events: none`），不得影响文字对比度。

## 6. 布局与响应式

| 断点 | 行为 |
| --- | --- |
| ≥1220px | 文档站三列手机并排；内容最大宽 1240 |
| 861–1219px | 文档站两列 |
| ≤860px | 单列；顶部导航收起；流程图纵向排列 |
| ≤480px | 手机框宽 340；内边距 12；字号不缩小到 12px 以下 |

- **设计基准**：375×812（iPhone 13 mini 逻辑尺寸）。原型中的 1px ≈ Taro 750 设计稿的 2rpx。
- **安全区**：底部固定 tabbar/CTA 必须留 `env(safe-area-inset-bottom)`；顶部自定义导航留状态栏高度。
- **滚动**：内容区独立滚动，固定栏不遮挡最后一项（底部 padding ≥ 84px）。
- **横屏**：MVP 不专门适配，但不得出现横向滚动。

## 7. 图标与插画

| 规则 | 标准 |
| --- | --- |
| 图标族 | 统一线性 SVG，24×24 网格，描边 1.7px，圆角端点 |
| 尺寸 | 16 / 20 / 24 / 32（以 4 为步进） |
| 禁止 | emoji 作为结构图标；位图图标；同一层级混用填充与线性 |
| 语义 | 纯装饰图标 `aria-hidden`；独立图标按钮必须有 `aria-label` / `accessibilityLabel` |
| 插画 | 全部内联 SVG 或 CSS 渐变，单文件不引外部图片；插画不参与交互 |
| 猫灵 | 见第 9 节，最小 56px 仍可辨识 |

**图标清单（首批）**：地图、指南针、书本、用户、火焰、叶子、锁、勾、时钟、箭头、分享、设置、麦克风（P2）。

## 8. 组件规范

### 8.1 按钮 Button

| 变体 | 背景 | 文字 | 用途 |
| --- | --- | --- | --- |
| Primary | 苔绿 `#3E6650` | 素笺 | 每屏唯一主行动 |
| Ghost | 透明 + 1.5px 墨线 | 深苔 | 次要行动（查看解析、返回） |
| Amber | 琥珀 | 深棕 | 领取奖励、限时动作（慎用） |
| Disabled | 陈纸 `#DED8C8` | 灰 | 不可用，保留语义 `disabled` |

- 高度 48px（≥44pt），圆角 999px，左右内边距 24px。
- 按下：下沉 3px、阴影从 4px 变 1px，**不改变布局尺寸**；hover 上浮 1px。
- 焦点：3px 琥珀外描边，偏移 3px。
- 文案：动词开头，2–4 字（"开始闯关""查看解析"），不用"点击这里"。

### 8.2 Chip / Tag

- 高度 28–32px，圆角 999px，字号 12px。
- 默认：陈纸底 + 淡墨字；选中：苔痕底 + 苔绿字 + 1px 苔绿边。
- 印章标签：仅"已通关/满星"，朱砂 1.5px 边框、6px 圆角、旋转 -2°。
- 可点 chip 的点击区扩展到 ≥44px（用透明 padding），视觉高度不变。

### 8.3 进度 Progress

- 轨道 8–12px，圆角 999px，底色陈纸。
- 填充：苔绿→青瓷渐变；经验条用琥珀→焦糖。
- 右端加 6px 墨晕（模糊白点），模拟笔锋。
- 必须同时提供数值文本（3/6 关），不能只靠长度表达。

### 8.4 答题选项 Option

| 状态 | 表现 |
| --- | --- |
| 默认 | 素笺底、1.5px 墨线、灰底字母圆 |
| 选中 | 苔痕底、苔绿 1.5px 边、实心苔绿字母圆 + 白字 |
| 正确 | 苔痕底 + 苔绿勾图标 + "正确"文字（不只靠颜色） |
| 错误 | 朱砂浅底 + 朱砂叉图标 + "你的选择"文字 |
| 禁用 | 降低对比、`pointer-events: none` |

- 最小高度 56px，选项间距 8–10px；长文本自动换行，不截断。
- 多选提示"选全才得分"；判断题固定 A 正确/B 错误。

### 8.5 关卡节点 Map Node

| 状态 | 视觉 | 可交互 |
| --- | --- | --- |
| 已完成 | 苔绿实心 + 白勾 | 可重玩 |
| 当前 | 琥珀实心 + 外发光 + 数字 | 可开始 |
| 未解锁 | 陈纸底 + 虚线边 + 锁图标 | 否，点击提示"完成上一关解锁" |
| 章末 | 当前/已完成同上，外加双环 | 需 3 星 |

- 直径 44–52px；标签在节点下方 8–12px，避免压线。
- 节点与路径用 SVG 绘制，缩放不糊。

### 8.6 星级 Star

- 三星制：正确率 ≥60% 一星、≥80% 二星、100% 三星。
- 实心琥珀、空心用陈纸描边（不用灰色）。
- 必须有文字说明（"80% · 二星"），不能只给图形。

### 8.7 徽章 Badge

- 圆形 64px，外圈 2px 琥珀、内圈 1px 虚线；图标线性 1.5px。
- 未解锁：陈纸底 + 虚线 + 锁；不显示"还差 XX"的诱导文案。

### 8.8 底部导航 Tabbar

- 4 项：闯关 / 探索 / 错题 / 我的；不超过 5 项。
- 高度 64–68px，圆角 24px，悬浮在底部 12px。
- 激活态：苔痕胶囊底 + 深苔字 + 图标上移 1px。
- 角标用数字（错题 3），不用纯红点。

### 8.9 输入 Input / Textarea

- 高度 48px（单行）/ 88–120px（多行），圆角 16px，素笺底 + 1.5px 墨线。
- 标签在输入框上方，不用 placeholder 代替标签。
- 字数计数放右下，超限变朱砂；错误提示紧贴输入框下方。
- 简答输入 600 字上限，实时计数。

### 8.10 Toast / 反馈

- 深松烟底 + 素笺字，圆角 999px，居中偏下，2.5s 自动消失。
- 成功用勾图标，失败用感叹号；文案 ≤16 字，不堆叠。
- 破坏性操作（放弃本关）用二次确认弹层，不用 toast 代替。

### 8.11 底部抽屉 Sheet

- 圆角 28px，顶部 36×4 抓手，背景素笺 97% 不透明。
- 只放一个主 CTA；高度不超过屏幕 45%。
- 必须有遮罩（松烟 32%），点击遮罩关闭。

## 9. 吉祥物「墨团」

### 9.1 设定

- 形态：黑色猫灵，毛笔状尾巴，琥珀大眼，白胸口，耳朵内侧淡朱砂。
- 性格：安静、好奇、不评判；像同伴，不像教练。
- 声音（文案）：短句、具体、不说教。例："这一处我们再看看"而不是"你又错了"。

### 9.2 姿态与使用

| 姿态 | 使用场景 | 尺寸 |
| --- | --- | --- |
| 待机（睁眼） | 首页 Hero、空状态、加载 | 132–250px |
| 开心（月牙眼） | 通关、满星、连续学习 | 132px |
| 思考（眯眼+问号） | AI 生成中、简答批改中 | 78–132px |

- 每屏最多一只；地图页只放在当前节点旁。
- 不遮挡题干、选项、按钮；不叠加在文字上。
- 不做"摇头/哭泣"等负面表演；答错时蹲下或陪伴即可。

### 9.3 禁止

- 不复制官方角色花纹/比例；不做拟人化穿着；不做表情包式夸张。
- 不用于付费墙的诱导；不出现在加载超过 2 次的同一屏。

## 10. 动效规范

| 场景 | 时长 | 缓动 | 说明 |
| --- | --- | --- | --- |
| 按下反馈 | 140ms | ease-out | 位移 1–3px，不改变布局 |
| Hover | 160ms | ease-out | 仅桌面/文档 |
| 进度增长 | 320ms | ease-out | 数值同步滚动 200ms |
| 题目切换 | 240ms | ease-out | 横向 24px + 淡入 |
| 印章落下 | 320ms | cubic-bezier(.2,.8,.2,1) | 一次回弹，不循环 |
| 猫灵漂浮 | 5.2s | ease-in-out | ±12px，循环 |
| Toast | 200ms 进 / 160ms 出 | ease-out | 2.5s 驻留 |

- 同屏最多一个循环动画；列表 stagger 不超过 60ms/项。
- 禁止动画 width/height/top/left；用 transform/opacity。
- `prefers-reduced-motion: reduce` 时全部关闭，仅保留即时状态切换。

## 11. 无障碍

| 项 | 要求 | 落地 |
| --- | --- | --- |
| 文字对比 | 正文 ≥4.5:1；大字 ≥3:1 | 已用松烟/淡墨/远山；琥珀与朱砂禁作正文 |
| 非文字对比 | 图标/边框 ≥3:1 | 苔绿/墨线满足；禁用浅灰图标传达状态 |
| 点击区 | ≥44×44pt（iOS）/48dp（Android） | 图标按钮 36px 视觉 + 透明扩展 |
| 焦点 | 可见 3px 琥珀环 | H5 `:focus-visible`；小程序用选中态 |
| 颜色非唯一 | 状态同时有图标/文字/线型 | 节点：勾/锁/数字；选项：勾/叉 + 文案 |
| 读屏 | 图标按钮有名称；状态变化有播报 | `aria-label` / `accessibilityLabel`；生成进度用 `aria-live` |
| 字号缩放 | 200% 不遮挡、不截断 | 不写死文字容器高度；按钮可换行 |
| 动效 | 尊重 reduced-motion | 见第 10 节 |

## 12. 设计令牌（可直接落地）

