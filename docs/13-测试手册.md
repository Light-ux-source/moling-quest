## 1. 测试金字塔

```
        ┌─────────────────────┐
        │ 手动真机/视觉验收     │  ← 未执行（微信真机）
        ├─────────────────────┤
        │ H5 E2E（Playwright） │  ← scripts/e2e.js
        ├─────────────────────┤
        │ API 测试（httpx）     │  ← tests/test_api.py / test_chapters.py
        ├─────────────────────┤
        │ 单元测试（纯函数/链） │  ← settlement/search/chains/units
        └─────────────────────┘
```

原则：
- 业务规则（星级/经验/去重/判分/归一化）必须有纯函数单测。
- 每个接口至少覆盖成功 + 主要错误码。
- AI 调用在测试中一律 Mock；真实请求形状用 `httpx.MockTransport` 验证，不联网。
- E2E 只覆盖主流程与关键布局，不替代单测。

## 4. 测试夹具（conftest）

`backend/tests/conftest.py`：

```python
@pytest.fixture(autouse=True)
def _isolated_env(tmp_path, monkeypatch):
    monkeypatch.setenv("SQLITE_PATH", str(tmp_path / "test.db"))
    get_settings.cache_clear()
    db._initialized = False
    llm._llm = None
    search._search = None
    routes._rate.clear()
    db.init_db()
    yield
    ...
```

- **每个测试独立 SQLite**，避免顺序耦合。
- 清理 `llm/_search` 单例与限流桶。
- `client` fixture：`httpx.ASGITransport`，不启真实端口；BackgroundTasks 在响应返回前完成，所以创建后可直接查 ready。
- `monkeypatch` 用于注入失败 LLM / 报告降级。

**注意**：`get_settings` 是 `lru_cache`；改 env 后必须 `cache_clear()`。`app.main` 的模块级 `settings` 只用于 CORS/版本，不参与业务判断。

## 6. H5 E2E

`miniapp/scripts/e2e.js`：

1. 首页加载 → 布局检查。
2. 点 tabbar「探索」→ S06。
3. 输入主题 → 生成 → S07 → 预览 S08。
4. 开始闯关 → 逐题作答（选项/简答）→ 提交。
5. S04 结算 → 查看解析 → S05 报告。
6. 展开第一题解析，统计 `review-item` = 5。
7. 375/390/768 三档检查 `scrollWidth <= clientWidth`。
8. 控制台错误/404 为 0 → `E2E PASS`。

**已知坑**：
- H5 是 hash 路由，直接访问页面必须 `/#/pages/...`。
- Taro 页面切换期间旧页面仍在 DOM，`layoutReport` 需等 800ms；截图用 `.page-shell:visible`。
- 截图会等待字体；Chromium 有无限动画时用 `animations:'disabled'`。
- Google Fonts 在受限网络会失败；脚本拦截并过滤 `ERR_FAILED`。

## 8. CI 建议

```yaml
jobs:
  backend:
    steps:
      - uses: actions/setup-python@v5
        with: { python-version: "3.9" }   # 与生产依赖一致
      - run: pip install -r backend/requirements.txt
      - run: cd backend && python -m pytest -q
  frontend:
    steps:
      - uses: actions/setup-node@v4
        with: { node-version: "22", cache: npm, cache-dependency-path: miniapp/package-lock.json }
      - run: cd miniapp && npm ci && npx tsc --noEmit && npm run build:weapp && npm run build:h5
```

E2E 需要起后端 + 静态服务；可作为 nightly 或 release job。当前仓库未提交 CI（避免未确认成本/权限）。
