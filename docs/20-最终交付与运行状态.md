## 2. 微信配置状态

- `backend/.env` 中 `WECHAT_APP_ID`、`WECHAT_APP_SECRET` **已填写**（不在文档/仓库中记录具体值）。
- 重启后 `/api/v1/health` 的 `wechat_login` = **true**。
- 配置校验：用无效 code 调官方 `code2Session`，返回：

```text
errcode: 40029
errmsg: invalid code
```

`40029` 表示 code 无效，而不是 `40125 invalid appsecret`，说明 **AppID + AppSecret 已被微信接受**。通过本项目 `POST /api/v1/auth/wechat` 以无效 code 探测，返回 **400** 与「登录凭证无效，请重试」，说明 API 错误映射正常。真实登录仍需小程序端 `wx.login()` 产生的新 code；建议在微信开发者工具/真机再走一次。

**安全**：AppSecret 只存在后端 `.env`（已 gitignore）；可提交模板是 `backend/.env.example`（AppID/Secret 为空）。`python3 scripts/check_env_example.py` 校验通过。

## 5. 重启与复现

```bash
# 1) 开发 MySQL（独立 3307）
cd backend
./scripts/start_mysql_dev.sh

# 2) 后端（读取 backend/.env）
.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000

# 3) H5
cd ../miniapp
HOME=$PWD/.home npm run build:h5
python3 scripts/serve_h5.py dist-h5 10087

# 4) 测试
cd ../backend && .venv/bin/python -m pytest -q
cd ../miniapp && npx tsc --noEmit && node scripts/e2e.js
python3 ../scripts/check_env_example.py
```

**体验登录**：H5 登录弹层点“体验登录（开发）”；生产环境由 `ENV=production` 自动关闭。
