## 1. 产品术语

| 术语 | 含义 |
| --- | --- |
| 墨灵闯关 | 产品名；治愈手绘纸感 + 原创猫灵「墨团」 |
| 墨团 | 原创黑猫灵吉祥物；AI 的化身，不是《罗小黑》角色 |
| 章节 Chapter | 一次 AI 生成的学习单元；当前 1 次生成 = 1 章 |
| 关卡 / 节点 Node | 章节地图上的一个节点；5 道题 = 5 个节点 + 章末综合 |
| 章末综合 | 前 5 关均 3 星后解锁的 3 题综合关 |
| 会话 Session | 一次“主题 → 出题 → 答题 → 报告”的完整记录；`s_` 开头 |
| 提纲 Brief | 从检索资料提炼的 `key_points/misconceptions/prerequisites` |
| rubric | 简答题的判分要点/评分细则 |
| 结算 Settlement | 星级、经验、连击、段位、解锁 |
| 段位 Rank | S1 初入雾林 → S6 林间隐者 |
| 星级 Star | 60% 一星 / 80% 二星 / 100% 三星 |
| 经验 Exp | `correct*20 + stars*20`；日挑战全对 +30 |
| 连击 Combo | 最长连续答对题数 |
| 知识缺口 Gap | 来自错题的具体薄弱点 |
| 下一步 Next step | 可执行的学习动作 |
| 日挑战 | 3 题小关卡；daily kind；无章末 |
| Mock 模式 | 无 Key 时的确定性假数据，验证链路 |
| 真实模式 | `mode=deepseek`；调用 DeepSeek API |
| AI 初稿 | S08 预览的标识；允许重新生成 |
| 探索 | tabbar 项；当前映射 S06 造关页 |
| 错题 / 我的 | tabbar 项；当前置灰（S09/S11 未实现） |

## 2. 技术术语

| 术语 | 含义 |
| --- | --- |
| Taro | 多端框架；本项目 4.3.2 + React 18 + TS |
| rpx | 小程序响应式单位；750 设计稿 |
| LCEL | LangChain Expression Language；`prompt \| model \| parser` |
| ChatDeepSeek | `langchain-deepseek` 提供的 DeepSeek ChatModel |
| ChatPromptTemplate | LangChain Prompt 模板；本项目用 mustache |
| JSON mode | `response_format={"type":"json_object"}`；DeepSeek 要求 Prompt 含 JSON |
| thinking | DeepSeek 思考模式；默认开启，本项目显式 disabled |
| rerank_score | Search API 相关性分数 0–3；≥1.5 为优质 |
| ASGITransport | httpx 直接调用 ASGI app，测试不启端口 |
| WAL | SQLite 历史模式；v0.3.0 已切 MySQL，当前不再使用 |
| client_id | 匿名设备 ID；`X-Client-Id` |
| session_id | 单次学习凭证；知道即可读该会话 |
| Settlement | 结算快照；报告里也带 |
| Report snapshot | `reports.payload` 固定快照 |
| E2E | Playwright H5 端到端 |
| Golden set | 黄金评测集（P1，未实现） |
| SSE | Server-Sent Events（P1 流式） |

## 6. 快速命令索引

```bash
# 后端测试
cd backend && .venv/bin/python -m pytest -q
# 前端类型/构建
cd miniapp && npx tsc --noEmit && npm run build:weapp && npm run build:h5
# H5 预览 + E2E
python3 scripts/serve_h5.py dist-h5 10087 & node scripts/e2e.js
# 资源/截图
python3 scripts/gen_assets.py
../backend/.venv/bin/python scripts/seed_demo.py --reset
node scripts/screenshot.js
```
