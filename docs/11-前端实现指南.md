### 1.1 尺寸换算（重要）

`config/index.ts`：

```ts
designWidth: 750,
deviceRatio: { 640: 1.17, 750: 1, 375: 2, 828: 0.905 }
```

- 原型 16px → 代码 `32px` → 小程序 `32rpx`（≈16px），H5 `0.8rem`（≈16px）。
- 写 CSS 时**不要**直接写 16px；先按原型×2。
- 自定义属性也会被转换（已实测 `--radius-l: 56px` → `56rpx` / `1.4rem`）。

## 3. 数据流

### 3.1 单向数据流

```
page (useState)
  → services/api.ts (Taro.request + X-Client-Id)
    → FastAPI
  ← JSON (SessionDetail/Report/Chapter/Profile)
  → setState → render
```

- **不引入 Redux/Zustand**：8 页、无复杂跨页共享；URL 参数 + 页面 state 足够。
- `sessionId`/`chapterId` 走路由参数；刷新/分享可恢复。
- 最近学习/草稿只存本地；题目/报告以服务端为准。

### 3.2 轮询

`pollSession(sessionId, { onUpdate, onNetworkError, stopAt, timeout })`：

- 间隔 1.2s；失败 ×1.6 退避，封顶 5s；总超时 120s。
- 命中 `ready/completed` 返回；`failed` 抛 `ApiError(500, error)`；404 直接抛。
- 页面用 `alive` ref 防止卸载后 setState。
- 不要并发多个轮询；页面卸载/取消时停止。

### 3.3 本地存储

| Key | 内容 | 清理 |
| --- | --- | --- |
| `ml_client_id` | 匿名设备 ID | 不主动清 |
| `ml_recent_sessions` | 最近 6 组 `{id,chapterId,topic,level,status,stars,createdAt}` | 覆盖式 |
| `ml_quiz_drafts` | `{sessionId: {answers,currentSeq,updatedAt}}`，最多 6 份 | 提交成功后 `clearDraft` |

> Taro H5 的 `getStorageSync` 返回的是写入值；底层 localStorage 实际存 `{"data": ...}`。E2E 预置 `client_id` 时需写 `JSON.stringify({data})`（见 `scripts/screenshot.js`）。

### 3.4 请求头

```ts
header: {
  'Content-Type': 'application/json',
  'X-Client-Id': getClientId()
}
```

`getClientId()` 首次生成 `ml_<time>_<rand>` 并写本地；所有请求自动带。

| 组件 | 用途 | 关键 props |
| --- | --- | --- |
| `Icon` | SVG 图标 | `name`、`size` |

| `StarRating` | 三星（amber/hero） | `stars`、`size`、`animate` |

| `ProgressBar` | 苔绿/琥珀进度 | `value`、`max`、`tone` |
| `LoadingOrb` | 墨团 + 文案 + 三点 | `title`、`subtitle` |
| `EmptyState` / `ErrorCard` | 空/错状态 | `title`、`text/message`、CTA |

### 4.3 资源生成（不要手改 SVG）

```bash
python3 scripts/gen_assets.py
```

- 从原型 SVG 生成 `assets/icons/*.svg`（颜色变体）、`mascot/*.svg`、`map/path-3/5/8.svg`；
- 生成 `utils/mapLayout.ts` 节点坐标；
- 生成 `styles/noise.css`（96×96 PNG base64 纸纹）。

**微信限制**：小程序端不能 JSX 内联 `<svg>`；`<image>` 支持 SVG，但不支持 `<style>`/百分比单位。生成脚本已规避（ADR-019）。

### 4.4 字体

- H5：`src/index.html` 引 Google Fonts（`display=swap`）；网络不可达时回退 `STKaiti/Songti SC/STSong`。
- 小程序：不加载外部字体，直接用系统字体，避免首屏阻塞（ADR-014）。
- 因此不同设备的字形/换行会略有差异，属已知限制。

## 5. 页面实现要点

### S01 首页
- 数据：`getProfile()` + `getChapters(4)` + `health()`（并行）。
- 主卡选择：生成中 > ready > failed > 最近完成；无章节时 CTA=造关。
- 日挑战：`createSession({kind:'daily', count:3})` 后直接进 S07。
- 状态：加载骨架、错误卡、Mock 提示。

### S02 章节地图
- `getChapter(chapterId)` + `getProfile()`。
- 节点布局：`NODE_LAYOUTS[3/5/8]` + `FINAL_POSITION`；SVG 路径按题数选 `path-3/5/8.svg`。
- 底部抽屉为唯一 CTA：开始/查看报告/生成章末/重试。
- 未解锁点击 toast；地图无额外进度卡（严格按原型）。

### S03 答题
- `getSession` → 生成中跳 S07、已完成跳 S04。
- 草稿：`loadDraft`/`saveDraft`；当前关：`startSeq` 或草稿或 `current_seq`。
- 选项：单选/判断点击即选；多选 toggle；简答 `Textarea` 600 字。
- 底部固定：上一题/下一题/提交 + 圆点；提交前空答 `Taro.showModal`。
- 每次切题 `updateProgress`（失败静默），并 `pageScrollTo(0)`。

### S04 结算
- 先 `getSession`；未 completed 则 `pollSession` 到 completed；再 `getSettlement`。
- 星级逐颗点亮（120ms/颗）；印章 320ms 落下；`prefers-reduced-motion` 关闭。
- 未达标不出现“失败”；主按钮变“重练本关”（新建会话）。

### S05 报告
- `waitForReport`（轮询到 completed 再取报告）；加载中 `LoadingOrb`。
- 分题型条、缺口、下一步、逐题折叠（答案/正确答案/反馈/解析/rubric/来源）。
- 来源点击复制；建议主题点击新建同主题会话；AI 免责声明 + usage。
- 分享：weapp `showShareMenu` + `useShareAppMessage`；H5 复制链接。

### S06 造关
- 200 字、示例 chips、难度/题量/题型；至少一种题型。
- 提交 `createSession(kind:'standard')`；防重复提交；错误内联。
- 预填 `?topic=`（`safeDecode`）。

### S07 生成中
- 轮询三步真实映射：searching → digesting → generating。
- 进度条用后端 `progress`，不做假动画。
- 失败原位 ErrorCard：重试（`retrySession`）/换主题；>45s 给“继续等/稍后回来”。
- 取消只停止轮询，不清服务端任务。

### S08 预览
- `getSession`；未 ready 跳 S07。
- 章节卡、题目列表（标题+题干两行+题型）、来源、AI 初稿标识。
- 重新生成二次确认（新会话，不删旧章节）；开始闯关 → S03。

## 6. 安全区、导航与双端差异

| 项 | 处理 |
| --- | --- |
| H5 | `useSafeArea` 返回 0；`PageHeader` 高 44px；无胶囊 |
| 微信 | `statusBarHeight` + `getMenuButtonBoundingClientRect()` 计算 nav 高度；header 右侧留 200rpx 给胶囊 |
| 底部 | `.tabbar`/footer 用 `env(safe-area-inset-bottom)`；页面底部留白 200–340px |
| 横向 | `page-shell max-width: 1040px`；页面 `overflow-x: hidden`；E2E 检查 375/390/768 |
| 点击区 | 主按钮 48px；footer 44px；图标按钮/ chip 用 `::after` 扩大命中区（视觉高度不变） |
| 动效 | 全局 `prefers-reduced-motion` 关闭；同屏最多一个循环动画 |

**微信端注意**：
- `<image>` SVG 不支持 `<style>`/百分比；资源由脚本生成。
- `:active` 的按下反馈在部分基础库不生效；需要时可加 `hover-class`（当前未全面加）。
- `gap` 在旧基础库可能不生效；目标基础库 2.x+，M3 真机确认。

## 8. 新增页面清单

1. 在 `src/pages/<name>/` 建 `index.tsx`、`index.css`、`index.config.ts`。
2. 在 `app.config.ts` 的 `pages` 注册。
3. 用 `PageShell` + `PageHeader` 包裹；需要 tabbar 时传 `tabbar`。
4. 类型加 `types.ts`；请求加 `services/api.ts`。
5. 处理加载/空/错/弱网；加 `alive` 防卸载 setState。
6. 若用新图标/图形：改 `scripts/gen_assets.py` 后重新生成，不要手写 SVG。
7. 更新 `docs/03` 与 `docs/05`；跑 `tsc`/双端构建/E2E/截图。
