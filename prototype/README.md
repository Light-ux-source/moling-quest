## 风格方向

**一句话**：把学习进度做成一条雾林小路，AI 是一只陪你走的黑猫灵。

| 维度 | 决策 |
| --- | --- |
| 关键词 | 治愈手绘、宣纸、墨线、森林晨雾、琥珀猫瞳、轻微不完美 |
| 主色 | 苔绿 `#3E6650`（行动/已完成） |
| 强调 | 琥珀 `#E0A23C`（当前关/经验/猫瞳） |
| 背景 | 宣纸 `#F7F2E4`，卡片素笺 `#FFFDF6` |
| 警示/印章 | 朱砂 `#BF5B42`，仅用于印章、错误、重要提醒 |
| 标题字 | Ma Shan Zheng（毛笔）→ 回退 STKaiti/KaiTi |
| 正文字 | Noto Serif SC → 回退 Songti SC/STSong |
| 形态 | 20–28px 大圆角、1.5px 墨线、4px 实色投影按钮、微旋转卡片 |
| 吉祥物 | 原创「墨团」：黑猫、毛笔尾、琥珀大眼、白胸口。**不使用《罗小黑》官方角色素材** |
| 动效 | 漂浮 5.2s、进度 320ms、印章落下 320ms；尊重 `prefers-reduced-motion` |

## 关键交互决策

1. **每屏一个主行动**：首页只有"继续闯关"，地图只有"开始闯关"，结算只有"下一关"。
2. **进度用路径表达**：地图节点 + 虚线路径，而不是顶部一条进度条；已完成/当前/未解锁三态区分明显（颜色 + 图标 + 虚实线，不只靠颜色）。
3. **答题不抖动**：题干区固定高度，选项数量变化不推动底部按钮；未答提交二次确认。
4. **等待可解释**：AI 生成拆成"检索 → 提炼 → 出题"三步，状态真实映射后端，不做假动画；失败在原位重试。
5. **分享不泄题**：分享图只含主题、星级、正确率、诊断，不含题干与答案。
6. **情绪不过载**：吉祥物只出现在等待、答错、通关等情绪节点，不遮挡题干与按钮。

## 待确认（回复序号即可）

1. 风格：治愈手绘纸感是否需要更"童趣"或更"水墨"？
2. 首页信息密度：保持现在（主卡 + 2 章节 + 每日挑战）还是更空？
3. 答题：一题一屏（当前）还是一组题滚动？
4. 章节规模：每章 6 关还是 3 关？章末综合关是否要 3 星解锁？
5. AI 生成：一次生成 5 关小章节（当前）还是 1 关一组题？
6. 排行榜是否进首版？（建议 P2）
7. 朱砂印章、微旋转卡片是否可接受？介意"不整齐"的话可全部拉正。
